# 数学冒险

10 以内加减法互动游戏，包含计分系统和进度反馈。

## 何时使用

用户提到**数学、加法、减法、算术、计算、口算**等关键词时激活此 Skill。

## 生成步骤

1. 根据年龄段确定数值范围（4-6 岁: 1-10, 6-8 岁: 1-20）
2. 参考 `assets/template.html` 的 HTML 结构和交互模式
3. 根据用户需求调整：
   - 数学运算类型（加/减/乘/除）
   - 难度递进方式（固定/渐进/随机）
   - 视觉主题（可更换颜色方案和装饰元素）
   - 题目数量和时间限制
4. 调用 generateGame 生成完整 HTML
5. 调用 evaluateGame 检查质量

## 评估重点

- 每道题的答案必须算术正确
- 答对/答错必须有明确的视觉和文字反馈
- 必须有计分系统且分数正确累计
- 题目必须随机生成（非固定题库）
- 难度应随答对次数递进
- 游戏区域内所有元素在可见范围内
- 必须有鼓励性的结束语

## 常见问题

- **答案计算错误** → 检查 JS 算术逻辑，确保使用 parseInt() 而非字符串拼接，验证运算符与期望结果一致
- **难度不递进** → 检查题目生成函数，确保数值范围随答对次数递增
- **计分不更新** → 确保 score 变量在答题正确时递增，且 DOM 中显示分数的元素实时更新
