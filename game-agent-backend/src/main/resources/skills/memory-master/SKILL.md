# 记忆大师

卡片配对翻牌记忆游戏，支持多种主题（动物/太空/海洋），适合 4-10 岁儿童。

## 何时使用

用户提到**记忆、翻牌、配对、卡片匹配、专注力训练**等关键词时激活此 Skill。

## 生成步骤

1. 根据年龄和难度确定卡片对数（4-6 岁: 4-6 对, 6-8 岁: 6-8 对, 8-10 岁: 8-10 对）
2. 参考 `assets/template.html` 的翻牌动画和配对逻辑
3. 根据用户需求调整：
   - 卡片主题（动物/太空/海洋/恐龙/水果等 emoji）
   - 网格布局（3 列/4 列/5 列）
   - 匹配后的动画效果
   - 是否需要计时器或步数限制
4. 调用 generateGame 生成完整 HTML
5. 调用 evaluateGame 检查质量

## 评估重点

- 卡片翻转动画是否流畅自然
- 同时只能翻开两张卡片，不能多翻
- 匹配成功的卡片保持显示，失败的自动翻回
- 步数和配对数正确计数
- 全部配对后有胜利提示
- 重新开始能正确重置游戏状态
- 所有卡片在可见区域内，不越界

## 常见问题

- **翻牌动画卡死** → 检查 CSS transition 和 JS 状态锁，确保翻牌完成后 isFlipping 标志重置
- **配对逻辑错误** → 验证卡片匹配判断使用 data 属性而非 DOM 位置，确保同一张卡片不能自我配对
- **卡片布局溢出** → 使用 CSS Grid 并限制 grid 容器高度，避免 aspect-ratio 导致卡片撑出视口
