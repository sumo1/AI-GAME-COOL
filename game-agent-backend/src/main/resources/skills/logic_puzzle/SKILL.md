# 逻辑推理大师

逻辑推理游戏，包含数列规律、图形排序、条件推理等题型，适合 8-12 岁儿童。

## 何时使用

用户提到**逻辑、推理、数列、规律、排序、思维训练、智力题**等关键词时激活此 Skill。

## 生成步骤

1. 确定题目类型比例（数列/图形排序/逻辑推理/数学应用题）
2. 参考 `assets/template.html` 的多题型切换和解析显示逻辑
3. 根据用户需求调整：
   - 难度级别（简单规律/多步推理/复杂条件判断）
   - 数值范围和运算复杂度
   - 是否显示解题思路和解析
   - 计时挑战模式或自由练习模式
   - 可加入提示系统（消耗分数获取提示）
4. 调用 generateGame 生成完整 HTML
5. 调用 evaluateGame 检查质量

## 评估重点

- 题目逻辑正确，答案无误
- 数列规律清晰可发现
- 逻辑推理题的条件完整无歧义
- 干扰选项合理（不能太明显也不能太刁钻）
- 解题解析清晰易懂
- 题目难度匹配 8-12 岁认知水平
- 计分和进度显示正确
- 游戏完成后有成绩评价和鼓励

## 常见问题

- **谜题无解或多解** → 在生成谜题后验证唯一解，使用回溯算法确认有且仅有一个正确答案
- **提示功能无效** → 检查提示逻辑是否正确排除已知信息，确保提示后缩小解空间
- **难度等级无区分** → 通过控制变量数量和约束条件数量来区分 easy/medium/hard
