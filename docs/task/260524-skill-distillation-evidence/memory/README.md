# memory — Skill 蒸馏证据层决策备忘录

本目录记录本任务实施过程中形成的架构判断。只写会影响后续设计的真实决策，不写流水账。

## 文件命名

```text
YYYY-MM-DD-{short-topic}.md
```

## 单条记录格式

```markdown
# {标题}

## 背景

为什么出现这个决策点。

## 决策

最终选择什么。

## 理由

为什么这么选，尤其要写清楚放弃了什么。

## 影响

影响哪些代码、文档、测试和后续任务。
```

## 已冻结的初始判断

- 当前运行时只保存最终产物，不保存足够的蒸馏证据。
- 第二层蒸馏需要结构化 evidence，不应该直接从自然语言日志里猜。
- 运行时只负责记录事实，不负责自动修改 `SKILL.md`。
- 证据层必须兼容现有 `sessions / messages / game_runs` 消费方。
